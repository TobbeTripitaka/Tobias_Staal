# Publications

`references.bib` contains every citable item (articles, submissions, datasets, software,
outreach, conference abstracts and theses) with full author names, DOIs, URLs and abstracts.
Copy any entry you need.

The file is **generated** from [`data/records.csv`](../data/records.csv) by
[`tools/build.py`](../tools/build.py); edit the CSV (or add to `data/new_entries.yaml`), not this file.
The formatted version is [`publication_list.pdf`](../publication_list.pdf).
